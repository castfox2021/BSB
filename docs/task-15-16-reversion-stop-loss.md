# Task 15·16 — 급락 반등 및 가상 자동손절

## 활성 범위

- 빗썸 전체 KRW 시장의 1·3·5분 하락률을 실시간 계산한다.
- 급락 관찰 기본값은 1분 -2%, 3분 -3%, 5분 -4% 중 하나이며 모두 로컬 설정으로 변경 가능하다.
- 진행 중인 봉은 급락 판정에 사용하지 않는다. 직전 1·3·5분의 완성 봉이 모두 연속해 존재할 때만 계산한다.
- 1분 급락만으로는 진입 감시를 시작하지 않는다. 1분 급락은 3분 누적 하락이 1.2% 이상 동반되어야 하며, 3분 또는 5분 급락 기준을 직접 충족한 경우도 감시한다.
- 저점 뒤 최소 5개의 완성 봉에서 변동폭 1.5% 이내의 바닥 다지기를 확인한다.
- 이어지는 완성 봉 2개가 모두 양봉이면서 종가와 저가를 연속으로 높여야 한다. 마지막 종가는 저점 대비 0.8% 이상이고 바닥 구간 고가를 0.2% 이상 돌파해야 한다.
- 최우선 매도호가가 확인 종가보다 0.3%를 초과해 높으면 뒤늦은 추격 진입으로 보고 가상매수를 차단한다. 최신 호가 안전검사도 그대로 적용한다.
- 실제 주문 경로와 연결하지 않는다. `live_execution=false`이며 기존 서버 측 주문 차단도 유지한다.

## 주 가상 정책

- structure 저점 아래 0.2%와 진입가 대비 최대 -1.5% 중 더 높은 가격을 최초 손절선으로 사용한다.
- 고정 익절은 없다.
- 수익률 +2.0% 도달 시 트레일링을 켜고, 최고가 대비 -1.0% 하락 시 청산한다.
- 손절선은 `max(기존 손절선, 새 손절선)`으로만 변경되어 내려가지 않는다.
- 10분이 지나도 최근 완료 봉이 상승하고 가격이 진입가보다 높으면 시간만으로 청산하지 않는다.
- 청산 뒤 같은 종목은 기본 30분 쿨다운한다.

## 병렬 가상 실험

동일 진입을 `structure_trailing`, `fixed_trailing`, `atr_trailing`, `structure_fixed_take` 네 개의 독립 150,000원 가상 계정에 복제한다. 마지막 정책의 +2.5% 고정 익절은 주 전략 규칙이 아니라 트레일링과의 성과 비교 전용이다. 승률, 평균 이익·손실, 수수료·슬리피지 반영 순손익과 MDD를 별도로 집계한다.

## 안전 및 장애 의미

- 오래된 시세나 호가, 비정상 스프레드·슬리피지, 불연속 최근 캔들은 신규 진입을 차단한다.
- 손절 가격을 건너뛴 급락은 손절가 체결로 가정하지 않고 실제 가상 호가 스윕 가격으로 손익을 기록한다.
- 노트북 절전·종료, 프로세스 중단 또는 데이터 연결 장애 중에는 로컬 보호가 동작하지 않는다.
- 실전 전환 전에는 포지션별 소유권/명시적 승인, 실제 잔고 재확인, 주문 ID 멱등성, 부분체결·재시도, 서버 상시 가동 또는 거래소 조건부 주문 지원 확인이 필요하다.
